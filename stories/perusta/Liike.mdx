## Ennen / jälkeen on 0 ms

Vedettävä jakaja seuraa osoitinta 1:1. Pienikin siirtymä tuntuu heti rikkinäiseltä,
koska käyttäjä odottaa suoraa vastetta sormeensa. Tämä on ainoa komponentti jossa
transition on tarkoituksella pois.

## Kunnioita prefers-reduced-motion

Reveal-säännöt ovat `no-preference`-median sisällä, joten ne eivät ole olemassa
käyttäjälle joka on pyytänyt vähemmän liikettä:

```css
@media (prefers-reduced-motion: no-preference) {
  .reveal { opacity: 0; transform: translateY(var(--reveal-shift)); }
  .reveal.is-in { opacity: 1; transform: none; transition: …; }
}
```

Komponentti ei tarvitse omaa haaraa — luokka vain ei tee mitään.
